## Shared count forms

These count forms are produced by the shared Arabic count helper and appear in
frequency, rest, warm-up, session, and counted-set labels.

| Count | Day | Group | Warm-up set | Session | Year | Second | Repetition |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 0 | 0 أيام | 0 مجموعات | 0 مجموعات إحماء | 0 حصص | 0 سنوات | 0 ثوانٍ | 0 تكرارات |
| 1 | يوم واحد | مجموعة واحدة | مجموعة إحماء واحدة | حصة واحدة | سنة واحدة | ثانية واحدة | تكرار واحد |
| 2 | يومان | مجموعتان | مجموعتا إحماء | حصتان | سنتان | ثانيتان | تكراران |
| 3–10 | {count} أيام | {count} مجموعات | {count} مجموعات إحماء | {count} حصص | {count} سنوات | {count} ثوانٍ | {count} تكرارات |
| 11+ | {count} يومًا | {count} مجموعة | {count} مجموعة إحماء | {count} حصة | {count} سنة | {count} ثانية | {count} تكرارًا |

Non-integer year values use “{count} سنة”. A fractional counted-set value
uses “{count} مجموعة محسوبة لكل عضلة”.

In oblique contexts the dual changes to يومين / مجموعتين / مجموعتي إحماء /
حصتين / سنتين / ثانيتين / تكرارين (for example, “last two days” and “rest for
two seconds”).
